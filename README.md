# 📰 Middle East Journal

A digital newspaper created for a **Geography class project** at **Colégio Militar de Juiz de Fora (Brazil)**. The assignment was to produce a newspaper on current world affairs, and this website is the digital edition, covering humanitarian crises in the Middle East and Asia. It is a lightweight single-page publication featuring maps, animated key statistics, and a story filter.

🔗 **Live site:** https://henriquebrtocosta.github.io/middle-east-journal/

> **Note:** The editorial content of the journal is written in Brazilian Portuguese.

## Overview

The project presents news reports and human-interest stories in a clean, readable newspaper layout. It is built with plain HTML, CSS, and JavaScript, with no frameworks or build tools, so it can be opened in any modern browser and hosted on any static platform.

## Featured Stories

- **Migration Crisis in Yemen:** escalating attacks on Saudi Arabia, cholera and measles outbreaks, food insecurity, and the humanitarian deadlock.
- **Humanitarian Crisis in Pakistan:** an overview of the situation in the country, with a political map.
- **Karim's Escape:** a personal account of religious persecution on the Arabian Peninsula.

## Features

- Story filter by country (All, Yemen, Pakistan)
- Key-statistics dashboard with animated counters
- Illustrative maps accompanying each report
- One-click "copy link" button for each story
- Single-file architecture with zero dependencies
